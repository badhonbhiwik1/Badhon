# Badhon Bhowmik — Personal Hub

## Files
- `index.html` — main website
- `style.css` — neon gradient / responsive design
- `app.js` — profile editor, wall, goals and mini games
- `assets/` — profile + club images

## How to use
1. Unzip the folder.
2. Open `index.html` in a browser.
3. Use **✦ Edit Info** or the **Update / Edit My Information** link at the very bottom.
4. Save your changes.

### Important
The built-in editor uses browser `localStorage`. That means edits are saved on the same browser/device where you make them. If you publish the site online, the changes are **not automatically shared with every visitor**.

To make one central online profile database, you would need a backend/database (for example Firebase, Supabase, or another server). The current version is intentionally static and works without a backend.

## Publishing
This folder can be uploaded to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or another static hosting service.
